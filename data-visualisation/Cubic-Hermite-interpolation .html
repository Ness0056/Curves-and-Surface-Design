DCS - 3.3 Cubic Hermite interpolation

Problem 4

Given P0 = (200, 200), P1 = (400, 300), v0 = (100, 100), and v1 = (100, 0), we compute the Hermite curve at t = 1/2.

The Hermite curve is defined as:

P(t) = h00(t)·P0 + h10(t)·v0 + h01(t)·P1 + h11(t)·v1

At t = 1/2, the basis functions are: h00 = 0.5, h10 = 0.125, h01 = 0.5, h11 = -0.125

Substituting the values:

x = 0.5·200 + 0.125·100 + 0.5·400 - 0.125·100 = 300
y = 0.5·200 + 0.125·100 + 0.5·300 - 0.125·0 = 262.5

Therefore: P(1/2) = (300, 262.5)

To make the curve pass through (300, 300) at t = 1/2 while keeping the same tangent directions, we scale the tangent vectors.

Let v0' = α·v0. Then the y-coordinate becomes:

y = 250 + 12.5·α

Setting y = 300:

300 = 250 + 12.5·α ⇒ α = 4

Since v1 only affects the x-direction (its y-component is 0), scaling v0 is sufficient to adjust the y-coordinate.

Final tangent vectors:

v0 = (400, 400)
v1 = (100, 0)
